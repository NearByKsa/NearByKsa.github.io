# Nearby — الموقع العام والسياسات

موقع رسمي لتطبيق **NearBy** — منصة وسيطة للطبخ والمنتجات المنزلية، للتعريف بالخدمات والأسعار والسياسات، بما في ذلك متطلبات بوابات الدفع.

- الأسعار: https://nearbyksa.github.io/pricing.html
- الاستبدال والاسترجاع: https://nearbyksa.github.io/refund.html
- الشروط والأحكام: https://nearbyksa.github.io/terms.html
- الخصوصية: https://nearbyksa.github.io/privacy.html
